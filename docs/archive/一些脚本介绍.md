关于PPT思路：

1. 源码级别的测试加入了插桩，可以利用覆盖率反馈的结束提高测试效率
同样的一个程序，在增加插桩之前只能通过无结果的模糊测试的方法进行测试，跑了很久也没有测出来
2. 模拟输入输出模块，方便检测运行效果，监测运行中的崩溃情况


今日新增脚本：

1. buildscript_new.sh

此脚本可以指定编译哪个文件

2. run_fuzz_all.sh

此脚本指定了一大堆文件，然后挨个进行模糊测试

3. 在命令行运行screen -S build_session，然后运行run_fuzz_all.sh脚本。然后按下组合键 Ctrl + A，然后松开，再按 D。你会看到屏幕提示 [detached]。这表示会话已与当前终端分离，并在后台继续运行，你现在可以安全断开连接。

这样，你就可以在后台运行模糊测试了。

4. 重新登录服务器时，可以screen -r build_session，就可以回到会话窗口了。
